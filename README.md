# Nova IPTV

مشغّل IPTV لأندرويد (Kotlin + Jetpack Compose + Media3). أضف السيرفر فيعرض لك: البث المباشر، الأفلام، المسلسلات، المفضلة، المشاهدة مؤخراً مع استكمال التشغيل، وتحميل الحلقات/المواسم للمشاهدة بدون إنترنت.

## أنواع السيرفرات المدعومة
| النوع | ماذا تُدخل |
|---|---|
| Xtream Codes | رابط السيرفر + اسم المستخدم + كلمة المرور |
| رابط M3U / M3U8 | رابط القائمة (رابط get.php يُحوَّل تلقائياً إلى Xtream) |
| ملف M3U | اختيار ملف من الجهاز |
| Stalker / MAG (تجريبي) | رابط البوابة + عنوان MAC |

يمكن إضافة أي عدد من السيرفرات والتبديل بينها من أيقونة السيرفرات.

## بناء الـ APK
**الطريقة 1 — GitHub Actions (بدون تثبيت شيء):**
1. ارفع المشروع إلى مستودع GitHub.
2. تبويب **Actions ← Build APK ← Run workflow** (أو يعمل تلقائياً عند كل push).
3. بعد الانتهاء حمّل `NovaIPTV-apk` من قسم Artifacts.
4. لإصدار رسمي: `git tag v1.0.0 && git push --tags` فيظهر الـ APK في صفحة Releases.

**الطريقة 2 — Android Studio:** افتح المجلد ← انتظر Sync ← Build ← Build APK(s).

> الـ APK موقّع بمفتاح debug ليُثبَّت مباشرة. للنشر على المتاجر أنشئ مفتاحك وعدّل `signingConfig` في `app/build.gradle.kts`.

## هيكل المشروع
- `data/Providers.kt` — مزوّدات السيرفرات (واجهة `IptvProvider`).
- `data/Db.kt` — Room: السيرفرات، المفضلة، السجل، التحميلات.
- `download/Downloads.kt` — طابور تحميل متتابع مع استكمال عند الانقطاع (WorkManager).
- `player/PlayerActivity.kt` — المشغّل + قائمة الحلقات/القنوات داخله + حفظ الموضع.
- `ui/` — الواجهات.

## إضافة نوع سيرفر جديد
1. أضف قيمة في `ServerType` (ملف `Models.kt`).
2. أنشئ class ينفّذ `IptvProvider` (`load` و`episodes` و`resolve` عند الحاجة).
3. سجّله في `Providers.create`، وأضف حقوله في `ServerEditScreen` إن احتاج.

## ملاحظات
- التحميل يعمل للأفلام والحلقات بصيغة ملف (mp4/mkv/ts). بث HLS (m3u8) والقنوات المباشرة لا تُحمَّل.
- بعض المزوّدين يحدّون عدد الاتصالات؛ لذلك التحميلات تُنفَّذ واحداً تلو الآخر.
- استخدم التطبيق مع محتوى لديك حق مشاهدته فقط.
